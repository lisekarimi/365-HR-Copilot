Human in the loop

The agent decides the easy cases. People decide the rest.

Every leave request is scored on duration and the clarity of its reason, then routed to exactly the right level of approval — so nothing risky is ever rubber-stamped.

🧭

Approvers are never hard-coded — the agent resolves the employee's manager (and their manager) from the Entra ID directory at request time, always following the live org chart.
